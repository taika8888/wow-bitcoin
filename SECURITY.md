# Security policy

## Report a vulnerability privately

Don't open a public issue for a security problem. Report it through GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the problem, the platform and app version, and the steps that show it.

Only the maintainers can see the report. They reply in the report's thread.

## Supported versions

Only the latest release gets security fixes.

## Scope

BTC Ticker makes only HTTPS GET requests to Kraken's public API and keeps its settings on your computer. The [Privacy](README.md#privacy) section of the README lists the exact requests. Examples of reports in scope are a way to make the app send other requests, run code from a settings file or a Kraken response, or take focus or input from the game.
